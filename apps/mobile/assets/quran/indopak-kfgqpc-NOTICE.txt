The text in indopak-kfgqpc.json is shipped as published by KFGQPC. It is extracted
from the document by scripts/build-indopak-texts.ts. No letters, vowel marks or
pause signs are changed. The only display normalisations are:
- runs of whitespace collapsed to a single space;
- a no-break space (U+00A0) before each ayah number so the number cannot wrap
  away from the last word;
- a combining grapheme joiner (U+034F) between U+064B and U+06E3 in 2:249, 3:34,
  9:66, 18:74, 27:52, 29:35, 43:28 and 59:7, so the font does not draw a pause
  sign that the text does not contain.

The text is designed for, and only renders correctly with, the KFGQPC Hafs
Nastaleeq font (HafsNastaleeq-Ver10.otf). See HafsNastaleeq-LICENSE.txt for the
font licence.
